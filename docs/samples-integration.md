The Proxy sample ring records only explicitly requested captures. `SampleRing::open(directory).await` requires an existing owned mode 0700 directory without symlink ancestors. The process removes previous-generation sample UUID files on restart; samples intentionally do not survive restart. Other directory entries are untouched. Mount or provision this directory separately from durable critical spool storage.

Control handler first verifies the authenticated actor and existing flow, then calls `request_capture(flow_id)` to obtain a generation UUID valid for 30 seconds. Repeated pending requests for the same flow return the same ID. Core should audit both capture request and sample reads using the authenticated actor; raw bytes and credentials must not enter audit/logs. GetSample returns only bounded bytes for this ID and expiry, never an arbitrary file path. A pending, evicted, expired or old-generation reference returns None. A new capture produces a new reference.

Flow transport calls `try_capture(flow_id, bytes)` before or after forwarding the same bytes. This uses try_lock and a bounded queue reservation, performs no filesystem calls, and copies at most 16 KiB for an active request. One next-chunk capture completes the request. The sampled bytes never affect forwarded bytes. More than 16 KiB sets truncated. Capacity or lock contention returns false and increments dropped(); parent should surface this counter as explicit sample loss. No automatic raw stream, whole-flow accumulation or indefinite recording exists.

Disk worker queue is 16 writes; active request map is 16; disk ring is 256 files at most 16 KiB each (4 MiB payload total). Ring eviction invalidates old IDs. A one-second cleanup removes expired files; logical expiry is enforced immediately on reads with a monotonic deadline. Files use 0600. One blocking disk worker serializes writes and cleanup; transport never waits for disk. Slow disk can lose captures explicitly. Bytes are transient and are not fsynced. Queue writes pending at shutdown drain before files are removed.

Public API: async `open(directory)->Result<Arc<SampleRing>>`, sync `request_capture(String)->Result<String>`, sync `try_capture(&str,&[u 8])->bool`, async `get(&str)->Result<Option<Sample>>`, sync `dropped()->u 64`. Sample fields: `data:Vec<u 8>`, `truncated:bool`, `expires_at:i 64` Unix seconds. HTTP DTO should format the timestamp as RFC 3339 and use appropriate binary/base 64 representation. Unit tests exercise requested-only capture, byte cap, request quota, expiry/generation IDs and a real 4 MiB disk quota/eviction.
